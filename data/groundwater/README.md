# Groundwater Dataset

## Dataset
Groundwater observations for the Nebraska study area covering 2000–2025.

## Files
- `Groundwater_2000_2025.csv` — consolidated groundwater observation dataset.
- `Groundwater_Clean.csv` — cleaned groundwater dataset used for subsequent processing and analysis.

## Variables

| Variable | Description |
|---|---|
| CSD_ID | Well/observation identifier |
| County | County associated with the observation |
| LatDD | Latitude in decimal degrees |
| LongDD | Longitude in decimal degrees |
| Surf_Elev | Surface elevation |
| YearMsr | Measurement year |
| DateMsr | Measurement date |
| Season | Season associated with the measurement |
| WatLevel | Recorded groundwater level |

## Study Period
2000–2025

## Study Region
Nebraska, USA

## Note
The yearly groundwater GeoTIFF surfaces generated through spatial interpolation are maintained separately from the tabular observation datasets. These derived surfaces should not be treated as independent groundwater observations.
